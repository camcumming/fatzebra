Fat Zebra Integration Test Harnesses

A set of browser-based developer tools for testing and exploring the three primary Fat Zebra payment integration approaches. Each harness exercises the full request/response cycle against the Fat Zebra sandbox environment — no backend required.

Sandbox only   No backend   Static / GitHub Pages

JS SDK fatzebra.js

Renders Fat Zebra's hosted payment form inside an iframe on your page via the fatzebra.js SDK. Handles 3DS2 authentication in-page and fires JavaScript events on tokenization and payment outcomes.

CredentialsaccessToken, username, sharedSecret
HashHMAC-MD5(secret, "reference:amount:currency")
OutcomeJS events parsed and displayed in-page (fz.payment.success, fz.payment.error)
SDK endpointcdn.pmnts-sandbox.io/sdk/v1/fatzebra.js
OAuth tokenFetched via curl (CORS blocks browser) — paste into Credentials modal

V3 Hosted Payment Page V3

Redirects the buyer to Fat Zebra's fully hosted payment page, or embeds it in an iframe. The harness builds and signs the URL, then opens it via redirect or iframe mode. FatZebra redirects back to return_path with result parameters.

Credentialsusername, sharedSecret
Hash inputreference:amount:currency[:return_path][:cards]
ModesRedirect, iFrame
Base URLpaynow.pmnts-sandbox.io/v3/{username}/…

Direct Post API

Posts card details directly to the Fat Zebra gateway. Supports two submission modes: Form POST (browser redirect to return_path) and JSONP (in-page response handling). The harness previews the full request before submit.

Credentialsusername, sharedSecret
Hash (Form POST)reference:cents:currency:return_path
ModesForm POST, JSONP
Endpointgateway.pmnts-sandbox.io/v2/purchases/direct
Open Direct Post harness →
Credentials — Each harness shares a single browser cookie (fz_creds, path /fatzebra/, 8-hour expiry). Enter your sandbox credentials once via the Credentials button in any harness nav bar and they are available across all three. The JS SDK harness additionally requires an accessToken. Sensitive fields (sharedSecret, accessToken) are masked in the UI; the values sent to the gateway are not altered.
